# Измерение скорости загрузки

Скрипт выполняет 10 последовательных HTTP(S)-загрузок, полностью читает каждый ответ
и выводит среднее время, общий объём и скорость. Python 3.12+, без внешних зависимостей.

## Запуск

Все команды выполняются из каталога проекта. Пример с изображением:

```console
python download_speed.py "https://www.w3.org/Icons/w3c_home.png" --timeout 30
```

Для проверки без внешнего интернета запустите в первом терминале:

```console
python -m http.server 8000 --bind 127.0.0.1
```

Во втором терминале:

```console
python download_speed.py "http://127.0.0.1:8000/README.md"
```

Сервер останавливается через `Ctrl+C`. URL передавайте в кавычках.
`--timeout` — таймаут отдельной сетевой операции в секундах: `0 < timeout <= 86400`,
по умолчанию `30`. Общая загрузка может длиться дольше.

## Что измеряется

- Время включает DNS, TCP/TLS, ожидание сервера, редиректы и полное чтение тела.
- Объём — фактически прочитанные байты всех тел, включая редиректы, без распаковки.
  Заголовки и служебный трафик TCP/TLS не учитываются.
- Среднее время = сумма длительностей / 10. Скорость = общий объём / сумма длительностей.
- Скорость выводится в **MiB/s**. **1 MiB = 1 048 576 байт**.

Ответы читаются блоками по 64 KiB без сохранения на диск. Редиректы разрешены только
между HTTP(S)-адресами и могут увеличить число HTTP-обращений сверх десяти загрузок.
Для оценки пропускной способности выбирайте большой файл: на маленьком преобладают задержки.

Иллюстративный результат:

```text
Average request time: 0.800000 s
Total downloaded: 83886080 bytes (80.000 MiB)
Download speed: 10.000000 MiB/s
```

## Ошибки

Первая ошибка останавливает запуск без повторных попыток. Сообщение об ошибке
выводится в `stderr`, итоговый отчёт при успехе — в `stdout`.

## Тесты и структура

```console
python -m unittest discover -s tests -v
```

Тесты используют локальный HTTP-сервер и работают без внешнего интернета.
`core.py` содержит загрузку, расчёты и форматирование; `cli.py` — аргументы и вывод;
`download_speed.py` — точка входа; `tests/` — основные регрессионные проверки.
